ステージB: AIに株の分析をしてもらって、ページに載せよう

この教室で作る分析は AI による参考情報です。投資判断はご自身の責任で行ってください。大切なお金を動かす前に、必ずご自身で確かめましょう。

このステージでは、AI（Claude）に気になる会社の様子を調べてもらい、その結果を自分のページに載せます。4つのゴールに分かれています。

ゴール 1 Claudeに株の分析をたのむ

この章が終わると…

気になる会社を 3 つ選んで、AI（Claude）に今日の様子を聞いてみます。ニュースを自分で調べなくても、やさしい言葉で教えてくれます。

  1. 気になる会社を 3 つ決めます（例: トヨタ、任天堂、NTT）。
  2. 下の「コピー」ボタンを押して、お願い文をコピーします。
  3. 会社名の部分を書き換えて、Claude の入力欄に貼り付けて送ります。
Claudeに貼り付ける文章 
あなたは慎重な株式アナリストです。次の日本の会社について、最近の様子を調べて教えてください: （会社名1）、（会社名2）、（会社名3）。
それぞれについて、①最近のニュース ②良い材料 ③心配な材料 ④総合的な見通し（強気・中立・弱気のどれか）を、専門用語を使わずに説明してください。
最後に必ず「この分析は参考情報であり、投資の判断はご自身で行ってください」と書いてください。

注記: Claude が Web 検索を使える設定だと、より新しい情報になります。

✅ できたかな？確認

😵 うまくいかないとき
会社名の書き換えを忘れて送ってしまった
もう一度コピーボタンから文章をコピーし、（会社名1）などの部分だけを書き換えて送り直しましょう。
Claude が「わかりません」と答える
会社名を漢字とカタカナの両方で試してみましょう。うまくいかないときは息子に電話してください。

ゴール 2 分析結果をWebページにしてもらう

この章が終わると…

さきほどの分析結果を、見やすいカード型の Web ページにしてもらいます。

  1. 同じ会話の続きで、下のお願い文を送ります。
  2. できた HTML を index.html という名前でデスクトップに保存します。
Claudeに貼り付ける文章 
いまの分析結果を、1 つの HTML ファイルの Web ページにしてください。条件: 文字は大きめ / 会社ごとにカード型で区切る / 見通し（強気・中立・弱気）は色つきのラベルにする / ページの上に今日の日付 / ページの下に「この分析は参考情報であり、投資判断はご自身の責任で行ってください」と表示。index.html という名前で保存できるようにしてください。

✅ できたかな？確認

😵 うまくいかないとき
ファイルがどこに保存されたかわからない
「ダウンロード」フォルダも見てみましょう。見つからないときは息子に電話してください。
見通しのラベルに色がついていない
そのまま進めても大丈夫です。気になるときは「見通しに色をつけてください」と Claude に追加で頼んでみましょう。

ゴール 3 GitHubの箱の中身を入れ替える

この章が終わると…

新しく作ってもらった index.html を、watashi-no-page の箱にアップロード（荷物を運び込むこと）して、中身を入れ替えます。

  1. GitHub で watashi-no-page を開きます。
  2. 「Add file」→「Upload files」を押します。
  3. 新しい index.html をドラッグして置きます。
  4. 下の緑色のボタン「Commit changes」を押します。

注記: 同じ名前のファイルを上げると、新しいものに置き換わります。前のページは消えますが、記録（コミット）には残っているので大丈夫です。

✅ できたかな？確認

😵 うまくいかないとき
「There are conflicts」のようなメッセージが出る
いちど画面を再読み込みして、もう一度 Upload files からやり直してみましょう。わからなければ息子に電話してください。

ゴール 4 更新されたページを確認する

おめでとうございます！

これで「AI の株分析が載った自分のページ」の完成です 🎉

  1. メモしておいた自分のURL（住所）を開きます。
  2. 表示が古いときは再読み込み（Ctrl + R）します。
  3. スマホでも見てみます。

✅ できたかな？確認

😵 うまくいかないとき
古いページのままに見える
Ctrl キーを押しながら R キーを押して、強く再読み込みしてみましょう。
何分待っても変わらない
Upload files のときに「Commit changes」を押し忘れていないか確認しましょう。わからないときは息子に電話してください。
