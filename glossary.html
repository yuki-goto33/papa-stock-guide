用語ミニ辞典

わからない言葉が出てきたら、このページを見てください。むずかしい言葉には、すべて「たとえ話」をつけています。読み方だけ分かれば、それで十分です。

GitHub（ギットハブ）

🗣 たとえると…
世界中の人が使う「貸し倉庫ビル」。自分の部屋（箱）を無料で借りられる

自分が作ったホームページの材料を保管しておく、インターネット上の場所です。

アカウント

🗣 たとえると…
倉庫ビルの「会員証」。名前とパスワードで作る

サービスを使うために必要な、自分専用の登録情報のことです。

リポジトリ

🗣 たとえると…
作品を入れる「箱」。箱ごとに名前を付ける

ホームページの材料（ファイル）をまとめて入れておく、箱のようなものです。

アップロード

🗣 たとえると…
自分のパソコンから箱へ「荷物を運び込む」こと

パソコンの中にあるファイルを、インターネット上の場所に送って置くことです。

コミット（保存）

🗣 たとえると…
箱の中身を入れ替えるときの「記録つき保存」。いつ何を変えたか残る

変更した内容を、記録を残しながら保存する操作です。

GitHub Pages（ページーズ）

🗣 たとえると…
箱の中身を世界に見せる「ショーウィンドウ」

箱（リポジトリ）の中身を、誰でも見られるホームページとして公開する仕組みです。

URL（アドレス）

🗣 たとえると…
ページの「住所」。これを教えれば誰でも見に来られる

インターネット上のページがある場所を表す、英数字の並び（住所のようなもの）です。

HTML

🗣 たとえると…
Web ページの「設計図」の書き方。Claude が書いてくれるので覚えなくてよい

ホームページの見た目や構成を決めるための書き方のルールです。難しそうに見えますが、Claudeにお任せで大丈夫です。

ブラウザ

🗣 たとえると…
インターネットを見る窓。Edge や Chrome のこと

インターネットのページを見るためのアプリです。パソコンに最初から入っていることが多いです。

ブックマーク（お気に入り）

🗣 たとえると…
よく行くページの「しおり」

よく見るページを、すぐに開けるように登録しておく機能です。

AI（Claude）

🗣 たとえると…
文章で頼みごとができる「とても物知りな助手」

文章で質問やお願いをすると、答えてくれたり作業を手伝ってくれたりするコンピューターの仕組みです。

プロンプト

🗣 たとえると…
AI への「お願いの文章」。コピペでよい

AIに何をしてほしいかを伝える文章です。この教室では、決まった文章をコピーして貼るだけで大丈夫です。

GitHub Actions（アクションズ）

🗣 たとえると…
倉庫ビルの「自動働きロボット」。決まった時間に作業を代行してくれる（発展編で登場）

あらかじめ決めておいた作業を、決まった時間に自動で行ってくれる仕組みです。発展編で使います。
