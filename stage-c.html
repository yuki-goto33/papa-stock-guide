ステージC: 自分のページをインターネットに公開しよう

このステージでは、あなた専用のホームページを、世界中の誰でも見られる形で公開します。6つのゴールに分かれているので、1日1ゴールくらいのペースで、ゆっくり進めて大丈夫です。

ゴール 1 GitHubのアカウントを作る

この章が終わると…

世界中の人が使う貸し倉庫ビル GitHub（ギットハブ） のアカウント（会員証）を作ります。これがあると、自分専用の箱を借りられるようになります。

  1. ブラウザ（インターネットを見る窓）で github.com を開きます。
  2. 画面右上にある「Sign up」を押します。
  3. メールアドレスを入れます。
  4. パスワードを決めて、紙にメモしておきます。
  5. ユーザー名（半角英数字）を決めます。
  6. 届いたメールに書かれている数字を入力します。
パスワードのメモは必ず紙に書いて、なくさないように保管しておきましょう。

✅ できたかな？確認

😵 うまくいかないとき
メールが届かない
迷惑メールフォルダを見てみましょう。それでも見つからないときは、息子に電話してください。
英語で不安
この絵と同じ場所だけ操作すれば大丈夫です。わからなくなったら、息子に電話してください。

ゴール 2 リポジトリ（作品を入れる箱）を作る

この章が終わると…

リポジトリ（作品を入れる箱）という、自分のページの材料を入れる箱を作ります。名前は watashi-no-page にしましょう。

  1. 画面右上の「＋」を押します。
  2. 「New repository」を選びます。
  3. 「Repository name」の欄に watashi-no-page と入れます。
  4. 「Public」のまま変更しません。
  5. 「Add a README file」にチェックを入れます。
  6. 緑色の「Create repository」を押します。
Public（パブリック）＝誰でも見られる、という意味です。本名や口座の情報は絶対に書かないようにしましょう。

✅ できたかな？確認

😵 うまくいかないとき
名前を間違えて作ってしまった
心配いりません。もう一度「New repository」から watashi-no-page という名前で作り直しましょう。わからなければ息子に電話してください。

ゴール 3 Claudeに自己紹介ページを作ってもらう

この章が終わると…

AI（Claude）にお願いして、自分だけの自己紹介ページの設計図（HTML）を作ってもらいます。

  1. Claude Desktop を開きます。
  2. 下の「コピー」ボタンを押して、お願い文をコピーします。
  3. Claude の入力欄に貼り付けて送ります。
  4. できあがった内容を index.html という名前でデスクトップに保存します。
Claudeに貼り付ける文章 
私のパソコンにはプログラミングの道具が入っていません。Web ページの設計図（HTML）を1つのファイルで作ってください。内容は、趣味の紹介ページです。趣味: （ここにお父さんの趣味を書く）。名前は本名ではなく『(ニックネーム)』としてください。文字は大きめ、やさしい色づかいでお願いします。できたら index.html という名前で保存する方法も教えてください。

✅ できたかな？確認

😵 うまくいかないとき
ファイルがどこに行ったかわからない
パソコンの「ダウンロード」フォルダを見てみましょう。見つからないときは息子に電話してください。

ゴール 4 箱にファイルをアップロードする

この章が終わると…

作ってもらった index.html を、watashi-no-page の箱の中にアップロード（荷物を運び込むこと）します。

  1. GitHub で watashi-no-page を開きます。
  2. 「Add file」→「Upload files」を押します。
  3. index.html をドラッグして置きます。
  4. 下の緑色のボタン「Commit changes」を押します。

✅ できたかな？確認

😵 うまくいかないとき
ドラッグがうまくできない
「choose your files」という文字を押すと、ファイルを選ぶ画面が開きます。そこから index.html を選んでも大丈夫です。

ゴール 5 GitHub Pages（ショーウィンドウ）を有効にする

この章が終わると…

GitHub Pages（ページーズ）という仕組みを使って、箱の中身を世界中に公開します。

  1. 箱の上にあるタブ「Settings」を押します。
  2. 左側のメニューから「Pages」を押します。
  3. 「Branch」の「None」を「main」に変えます。
  4. 「Save」を押します。
  5. 1〜2分待ってから、ページを再読み込みします。
  6. 上に出てきたURL（住所）を押します。

✅ できたかな？確認

😵 うまくいかないとき
404 と出る
2〜3分待ってから、もう一度再読み込みしてみましょう。
Save が見つからない
Branch を main にすると、Save ボタンが出てきます。

ゴール 6 スマホで自分のページを見る

おめでとうございます！

あなたのページは、世界中のどこからでも見られます 🎉

  1. スマホで LINE などを開きます。
  2. 自分宛てに URL を送ります。
  3. スマホで開きます。
  4. 家族にも送ってみます。

✅ できたかな？確認

😵 うまくいかないとき
スマホで開いても表示されない
数分待ってから、もう一度リンクを開いてみましょう。それでも難しいときは息子に電話してください。
