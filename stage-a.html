ステージA: 毎朝の日課にしよう

この教室で作る分析は AI による参考情報です。投資判断はご自身の責任で行ってください。大切なお金を動かす前に、必ずご自身で確かめましょう。

ここまでで、AI（Claude）に株の分析をしてもらい、自分のページに載せる方法が分かりました。このステージでは、それを「毎朝15分の日課」にするための準備をします。3つのゴールに分かれています。

ゴール 1 朝のお願い文を自分用に仕上げる

この章が終わると…

ステージBで使ったお願い文を、自分がいつも見たい会社用に書き換えて、毎朝すぐ使えるファイルとして保存します。

  1. 下の「コピー」ボタンを押して、お願い文をコピーします。
  2. 文章の中の「（会社名1）、（会社名2）、（会社名3）」の部分を、自分がいつも見たい会社の名前に書き換えます（2 社でも 3 社でもかまいません）。
  3. メモ帳を開いて貼り付け、asa-no-onegai.txt という名前でデスクトップに保存します。
Claudeに貼り付ける文章 
あなたは慎重な株式アナリストです。次の日本の会社について、最近の様子を調べて教えてください: （会社名1）、（会社名2）、（会社名3）。
それぞれについて、①最近のニュース ②良い材料 ③心配な材料 ④総合的な見通し（強気・中立・弱気のどれか）を、専門用語を使わずに説明してください。
最後に必ず「この分析は参考情報であり、投資の判断はご自身で行ってください」と書いてください。
分析のあと、そのまま 1 つの HTML ファイルにしてください。条件: 文字は大きめ / 会社ごとにカード型で区切る / 見通し（強気・中立・弱気）は色つきのラベルにする / ページの上に今日の日付 / ページの下に「この分析は参考情報であり、投資判断はご自身の責任で行ってください」と表示。index.html という名前で保存できるようにしてください。

✅ できたかな？確認

😵 うまくいかないとき
メモ帳で保存すると「.txt」が重なってしまう
ファイル名のところを asa-no-onegai.txt だけに書き換えれば大丈夫です。
どこを書き換えればいいかわからない
「（会社名1）、（会社名2）、（会社名3）」の部分に、見たい会社の名前を入れれば OK です（2 社でも 3 社でもかまいません）。わからなくなったら息子に電話してください。

ゴール 2 ブックマークを3つ整える

この章が終わると…

ブラウザ（インターネットを見る窓）のブックマーク（よく行くページのしおり）に、毎朝使う3つの場所を登録しておきます。

  1. 自分の公開ページを開いて、アドレスバーの右にある星マークを押し、お気に入り登録します。
  2. GitHub の watashi-no-page を開き、「Add file」→「Upload files」の画面を同じように登録します。
  3. Claude Desktop のアイコンを右クリックして、「タスクバーにピン留めする」を選びます。

✅ できたかな？確認

😵 うまくいかないとき
星マークが見つからない
ブラウザによって場所が少し違います。アドレスバーの右端あたりを探してみましょう。
タスクバーへのピン留めができない
アイコンを右クリックしたときに出るメニューから「タスクバーにピン留めする」を選びます。わからなくなったら息子に電話してください。

ゴール 3 朝のルーチンを一周やってみる

ここまで約 15 分。これが毎朝の日課です ☕

ゴール1・ゴール2 で準備したものを使って、実際に最初から最後まで、一人で通してやってみましょう。

  1. Claude Desktop を開きます。
  2. 保存した asa-no-onegai.txt を開いて、中のお願い文を貼ります。
  3. できあがった index.html を保存します。
  4. ブックマークから Upload files の画面を開きます。
  5. index.html をドラッグして、緑色の「Commit changes」を押します。
  6. 自分のページを開いて、今日の日付になっているか確認します。

✅ できたかな？確認

😵 うまくいかないとき
途中でどこまで進んだか分からなくなった
あわてなくて大丈夫です。どのステップで困ったかをメモして、息子に電話してください。
index.html の保存先を毎回忘れてしまう
ゴール1で asa-no-onegai.txt を保存した場所（デスクトップ）に合わせると、迷わずに済みます。
